# cyberpunk-terminal

Configuração de terminal estilo **cyberpunk**: tema do [oh-my-posh](https://ohmyposh.dev) + banner de "boot".

## Conteúdo

- `oh-my-posh/cyberpunk.omp.json` — tema principal
- `bin/cyberdeck-banner` — banner exibido ao abrir o terminal (desative com `CYBERDECK_BANNER=0`)
- `install.sh` — copia os arquivos e configura o `~/.bashrc`

## Instalação

```bash
git clone https://github.com/vinbeze/cyberpunk-terminal.git
cd cyberpunk-terminal && ./install.sh
```

Requer `oh-my-posh` e uma [Nerd Font](https://www.nerdfonts.com).
